Configuración necesaria

TEJILUME está en línea, pero faltan ajustes obligatorios del servidor. No pegues aquí claves ni contraseñas.

En Render: abre tu servicio → Environment → Add Environment Variable. Añade las variables indicadas y guarda para que Render vuelva a desplegar.

Genera dos secretos diferentes desde una terminal Node.js:

node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

Ejecuta el comando dos veces: una salida para SESSION_SECRET y otra para MASTER_KEY. ADMIN_PASSWORD debe tener al menos 12 caracteres. DATABASE_URL es la cadena PostgreSQL de Neon.
